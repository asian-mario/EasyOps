# Contributing

## Issues

Issues are very valuable to this project.

  - The Blender addon development community lacks a lot of development tools, so there will be mistakes, don't be afraid to report them!
  - Problems show where this project is lacking.
  - You can enhance user and developer experience!

Please and thank you for creating them.

## Pull Requests

Pull requests are a fantastic ways to improve and implement your ideas in the repository.

When deciding if I merge in a pull request I look at the following
things:

### Does it state intent

You should be clear which problem you're trying to solve with your
contribution.

For example:

> Change Boolean solver method in operators.py

Doesn't tell me anything about why you're doing that

> Change Boolean solver method in operators.py to improve interactions with object modifiers
> and improve stability

Tells me the problem that you have found, and the pull request shows me
the action you have taken to solve it.

### Is it of good quality

  - As long as you get your point through, grammar mistakes and spelling errors will be ignored
  - Written in English
  - It reads well


### Does it move this repository closer to my vision for the repository

The aim of this repository is:

  - To provide a high-quality hardsurface workflow tool for modern Blender versions
  - Invite a community of new and veteran 3D artists
  - Help inspire a community of open-source Blender Addon developers and KEEP it open-source, just as Ton Roosendaal intended.
